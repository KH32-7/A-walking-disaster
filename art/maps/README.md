# 지역 지도 그림

필드 지역의 위에서 본 지도 그림. 지도 화면(D-16)·출격 준비(D-07)·로딩 배경에 쓴다.

| 파일 | 크기 | 지역 |
|---|---|---|
| `flooded_mall_overview_4k.webp` | 4096 x 4096 | 침수 상가 (원본) |
| `flooded_mall_overview_2k.webp` | 2048 x 2048 | 침수 상가 (게임용) |

- 위쪽이 북쪽, 150 x 150 m를 덮는다. 글자·아이콘은 없으니 이름표와 마커는 UI가 위에 그린다.
- 만든 방법: 그레이박스(`levels/field/flooded_mall/layout.tscn`)를 위에서 찍은 색 구분 도면을 구조 참고로,
  Higgsfield Nano Banana Pro로 생성·편집하고 4K로 다시 그림. 직접 생성한 그림이라 공개 저장소에 둔다.
- 그림 속 강·해안선은 다듬어서 레이아웃과 조금 다를 수 있다. 레이아웃의 기준은 레벨 씬이다.
