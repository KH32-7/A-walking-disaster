# forest_clearing — 숲 공터 기지 시안 (레인 C 샌드박스)

`forest_clearing.tscn`을 열고 F6으로 실행한다. 게임에는 들어가지 않는다.

기지를 "공원 숲에 둘러싸인 빈 공터"로 바꾸는 시안이다. 실제 꾸미기(`levels/base/**/dressing.tscn`)와
건물 모델은 레인 D 소유라서, 이 폴더는 D가 옮겨 쓸 수 있는 참고본이다. 다른 레인 파일은 고치지 않는다.

## 구조 (200 × 150 m)

| 부분 | 크기 | 내용 |
|---|---|---|
| 공터 | 60 × 44 m (30 × 22칸), 모서리 반지름 9 m | 풀과 클로버만. 모든 건물을 여기에 짓는다 |
| 공원 숲 | 공터 바깥 전부 | 레드우드 나무, 고사리, 풀, 낙엽, 버섯, 바위, 쓰러진 통나무 |
| 연못 | 중심 (60, −6), 반지름 13 × 9 m | `art/shaders/water_toon.gdshader`(D) 사용, 둘레 자갈 |
| 흙길 | 공터 남쪽 → 맵 남쪽 끝 | 출격 출구 자리 |

## 파일

- `forest_clearing.gd` — 땅·연못·흙길 메시, 레드우드 흩뿌리기(MultiMesh, 시드 고정), 공터 건물 진열, 카메라.
  숲 밀도는 `tree_spacing`, `fern_spacing`, `grass_spacing`(m)로 조절한다.
- `building_models.gd` — 건물 42종 → American Suburb 모델 조합표(`MODELS`). 모델은 파일 이름으로 찾고,
  크기는 실행할 때 각 모델의 AABB로 맞추므로 수치를 몰라도 된다. 방송실(`radio_room`)은 시안용으로 3×3칸.

## 조작

WASD/방향키 이동, 휠 줌, Q/E 회전, B 건물 보이기/숨기기, L 건물 이름.

## 참고

- `assets/` 서브모듈이 없으면 땅과 연못만 나온다(CI 포함).
- 두 에셋 팩 모두 라이선스에 "AI 입력 금지" 조항이 있다. 이 씬은 파일 경로만 참조하고, 모델·텍스처나 렌더 화면을
  AI 도구에 넣지 않는다. 화면 확인은 사람이 에디터에서 한다.
