# UI·조작·접근성

UI의 원칙은 하나입니다. **중요한 정보는 항상 두 가지 이상의 방식으로** 전합니다(소리 + 화면, 색 + 모양, 아이콘 + 글). 조작은 키보드·마우스가 기본이고 게임패드를 지원합니다.

| 화면 | 열리는 때 | 주요 요소 |

## 기지 HUD

- **상단 막대**: 날짜·계절, 주요 자원 6종, 인구/침상, 전력, 습격 위협도 게이지(구간별 색 + 눈금).
- **하단 메뉴**: 건설, 주민, 무기고, 제작, 일지, 출격, 기지에 머무르기.
- **알림**: “○○이 배고파요”, “벌목장 일손 부족”처럼 행동으로 이어지는 알림만 띄웁니다. 누르면 해당 화면으로 갑니다.
- **주민 머리 위**: 필요 아이콘(배고픔·피로·아픔·슬픔), 대화 가능 표시.

## 접근성 설정

| 분야 | 설정 | 기본값 |
| --- | --- | --- |
| 자막 | 켜기, 크기 3단계, 배경 불투명도, 화자 이름·색 | 켜짐 |
| 소리 시각화 | 소음 링, 소리 방향 화살표, 중요 효과음 아이콘 | 켜짐 |
| 색 | 색약 필터 3종, 고대비 | 꺼짐 (모양 표시는 항상 켜짐) |
| 화면 | 흔들림 줄이기, 깜빡임·섬광 줄이기, 카메라 확대 | 보통 |
| 조작 | 키 재배치, 누르기↔토글(조준·달리기·막기), 한 손 프리셋, 조준 보조 3단계, 연타 대신 길게 누르기 | 조준 보조 약 |
| 속도 | 필드 게임 속도 0.5\~1.0 | 1.0 |
| 글 | 글꼴 크기, 읽기 쉬운 글꼴, 아이콘과 글 함께 표시 | 보통 |
| 메뉴 읽어주기 | 메뉴·대사를 TTS로 읽음 (Godot 내장 TTS) | 꺼짐 |
| AI 무전병 | 안내 빈도(끔·필요할 때·자주), 음성 켜기 | 필요할 때 |
| 난이도 | 보호 모드 항목별 켜기 (12 진행·밸런스 탭) | 보통 |

타이틀의 “접근성 빠른 설정”에서 자막·소리 시각화·색약·토글·보호 모드를 한 화면에서 고를 수 있게 합니다.

## UI 규칙

- 색만으로 구분하는 정보는 없습니다. 등급·속성·관계·위협도 모두 모양이나 글이 함께 있습니다.
- 자막은 한 번에 2줄, 선택지는 3개까지.
- 시간 제한이 있는 선택은 없습니다. 단, 필드에 있는 동안은 어떤 화면(일시정지·설정·긴급 귀환 포함)을 열어도 게임이 멈추지 않습니다. 화면이 열려 있는 동안 플레이어는 조작할 수 없습니다(2026-11-06 사용자 결정).
- 기지에서는 시간이 멈춰 있어 천천히 읽고 고를 수 있습니다.
