# 전투·클래스

클래스는 **총·칼·둔기** 3종이고, 주무기 계열이 곧 클래스입니다. 총은 강하지만 시끄럽고, 칼은 조용하고 빠르며, 둔기는 느리지만 단단한 마물을 깹니다. 소음 규칙 때문에 어떤 클래스를 고르느냐가 탐색 방식 자체를 바꿉니다.

## 클래스

| 항목 | 총 | 칼 | 둔기 |
| --- | --- | --- | --- |
| 역할 | 원거리 화력 | 은신·기동 | 근접 제압·버티기 |
| 공격 소음 | 15\~20m | 3m | 6m |
| 장점 | 사거리, 약점 사격 | 조용함, 출혈, 뒤치기 | 경직·넉백, 방어 파괴 |
| 단점 | 탄약 소모, 재장전, 소음 | 짧은 사거리 | 느린 공격, 스태미나 소모 큼 |
| 주무기 종류 | 권총, 기관단총, 소총, 산탄총, 저격총 | 단검, 마체테, 장검, 긴 날 창 | 파이프·렌치, 야구 방망이, 망치, 대형 해머, 방패+곤봉 |

| 패시브 (숙련 10) | 약점 피해 +30% | 출혈 2중첩 | 방어 파괴한 적에게 아군 피해 +15% |

- **클래스 변경**: 기지 훈련장에서 비용 없이 바꿉니다. 필드에서는 바꿀 수 없습니다.
- **보조무기 슬롯**: 계열과 상관없이 경량 무기(권총, 단검, 곤봉) 1개를 챙니다. 보조무기로 얻는 숙련 경험치는 50%입니다.
- **클래스 숙련 1\~10**: 그 계열 무기로 피해를 주거나 처치하면 오릅니다. 레벨당 그 계열 피해 +3%. 숙련은 계열별로 따로 쌓입니다.

| 항목 | 값 |

## 근접 전투

- **콤보**: 3타(칼 0.35초 간격, 둔기 0.6초). 3타째 피해 ×1.5.
- **막기**(우클릭): 정면 120° 피해 −50%. 막을 때마다 스태미나가 받은 피해 ×0.5만큼 줄고, 0이 되면 막기가 깨져 1초 경직.
- **완벽한 막기**: 맞기 0.2초 전에 막기를 시작하면 피해 0, 적 1초 경직.
- **뒤치기**: 적의 뒤쪽 90°에서, 적이 플레이어를 못 본 상태면 피해 ×2.

## 사격

- **조준**(우클릭): 확산 없음(조준점에 바로 꽂힘), 이동 속도 2.5m/s, 걷기 소음 0. 카메라가 살짝 당겨진다.
- **확산각**: 권총 6°, 소총 3°, 산탄총 20°(산탄 8개). 이동 중 ×1.5, 연사 시 한 발마다 +1°(무기별 상한).
- **탄약**: 권총탄, 소총탄, 산탄 3종. 루팅 또는 정비소 제작. 기본 권총(초반 지급)만 탄이 무한입니다.
- **엄폐**: 낮은 엄폐물 뒤 대상은 사격 피해 −50%, 높은 벽은 차단합니다.

## 피해 공식

```latex
D = A \times (1 + 0.06U) \times (1 + 0.03M) \times P \times E \times C \times \frac{100}{100 + R}
```

A = 무기 기본 공격력, U = 강화 단계(0\~10), M = 클래스 숙련(1\~10), P = 부위 배율(일반 1.0, 발광 핵 2.0), E = 속성 배율(약점 1.5, 저항 0.75, 그 외 1.0), C = 치명 배율(1.5, 확률 기본 5%), R = 대상 방어력. 둔기의 방어 파괴가 걸리면 5초 동안 R이 절반이 됩니다.

| 상태 이상 | 효과 | 주로 거는 것 |
| --- | --- | --- |
| 출혈 | 초당 3 피해, 5초 | 칼 |
| 경직 | 행동 불가 | 둔기, 완벽한 막기 |
| 넉백 | 1.5m 밀려남 | 둔기, 산탄총 |
| 방어 파괴 | 방어력 −50%, 5초 | 둔기 3타, 석 속성 |
| 둔화·속박·감전 | 06 마법·정수 탭 | 속성 무기 |

## 플레이어 레벨

- 처치, 구조, 탈출 성공으로 경험치를 얻습니다. 최대 30레벨.
- 3레벨마다 특기 1개를 고릅니다. 예: 가방 +2칸, 스태미나 +10, 구급상자 효과 +20%, 구조자 이동 속도 +10%, 문 따기 시간 −30%.

## 동행 주민 전투

- 동행 주민은 자기 클래스 적성과 장착 무기로 싸웁니다(07 주민 탭).
- **AI 모드**(V 키로 전환): 공격적(가까운 적 공격) / 신중(플레이어가 공격한 적만, 소음 최소) / 엄호(구조자 곁에서 방어).
- 체력 = 80 + 힘 × 5 + 방어구. 쓰러지면 30초 안에 일으켜야 하고(F 3초), 못 하면 고립됩니다.
- 클래스 스킬 1(Q)만 쓰며 쿨타임은 ×1.5. 아군 오인 사격은 없습니다.
