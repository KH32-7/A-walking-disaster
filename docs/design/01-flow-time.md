# 게임 흐름·시간

게임은 **하루** 단위로 돌아가고, 하루는 아침 → 출격 → 저녁 정산 → 밤의 4단계입니다. 출격하지 않고 기지에 머무는 날도 고를 수 있습니다.

## 하루 구조

| 단계 | 장소 | 시간 제한 | 하는 일 | 끝나는 조건 |
| --- | --- | --- | --- | --- |
| 아침 | 기지 | 없음 (시간 정지) | 작업 배정, 건설, 제작·강화·각인, 대화·선물, 출격 편성 | “출격” 또는 “기지에 머무르기” 선택 |
| 출격 | 필드 | 실시간 15분 (12분에 해질녘 경고, 15분부터 밤) | 탐색, 전투, 구조, 루팅 | 탈출 성공 또는 쓰러짐 |
| 저녁 정산 | 기지 | 없음 (연출 약 30초) | 생산 정산, 식량·연료 소모, 사기 변화, 하루 사건 요약 | 확인 버튼 |
| 밤 | 기지 | 습격 시 약 5분 | 습격 판정, 야간 이벤트(연애·고백·대화·꿈) | 습격 종료 또는 이벤트 없음 → 다음 날 아침 |

- **기지에 머무르기**: 출격 대신 하루를 기지에서 보냅니다. 플레이어가 작업에 참여해 그날 생산이 +20%, 주민 1명과 깊은 대화가 1회 추가됩니다. 낮 습격이 오면 직접 방어합니다. 식량·연료 소모는 똑같아서 계속 머무를 수는 없습니다.
- **필드의 밤**: 15분을 넘기면 마물 등장 ×1.5, 정예 마물 출현, 시야 −30%, 드롭 ×1.3입니다. 더 머물지 나올지는 플레이어가 고릅니다. 강제 종료는 없습니다.

## 게임 상태

| 상태 | 들어오는 조건 | 다음 상태 |
| --- | --- | --- |
| 타이틀 | 게임 실행 | 새 게임 → 프롤로그 / 이어하기 → 저장된 상태 |
| 기지\_아침 | 새 날 시작 | 출격 준비 / 기지\_머무름 |
| 출격 준비 | “출격” 선택 | 필드 (지역·장비·동행자 확정 후) / 기지\_아침 (취소) |
| 필드 | 출격 확정 | 결과 (탈출 또는 쓰러짐) / 기지\_낮습격 (긴급 귀환 선택 시) |
| 기지\_머무름 | “기지에 머무르기” 선택 | 기지\_낮습격 / 저녁 정산 |
| 기지\_낮습격 | 낮 습격 + 플레이어 기지에 있음 | 결과 또는 저녁 정산 |
| 결과 | 필드 종료 | 저녁 정산 |
| 저녁 정산 | 낮 종료 | 밤 |
| 밤 | 정산 확인 | 밤\_습격 / 밤\_이벤트 / 기지\_아침 |

일시정지, 설정, 생존 일지는 어느 상태에서나 열 수 있는 오버레이입니다. 기지에서는 시간이 멈춰 있고, 필드에서는 일시정지 중에만 멈춥니다.

## 계절

1년 = 60일, 계절당 15일입니다.

| 계절 | 효과 | 분위기 |
| --- | --- | --- |
| 봄 | 텍밭 생산 +20% | 꽃잎이 흩날림 |
| 여름 | 장마: 침수 지역 수위 상승(이동 경로 변화), 물 계열 마물 +30% | 빗소리, 안개 |
| 가을 | 채집·생산 +10% | 낙엽 |
| 겨울 | 텍밭 생산 −50%, 연료 소모 +1/일, 사기 −5(난방 기구 있으면 0) | 눈, 얼어붙은 수면 |

## 저장

- **자동 저장**: 아침 시작, 출격 직전, 탈출 직후.
- **필드 중 종료**: “중단 저장” 1개를 만들고, 불러오면 이어서 진행한 뒤 지웁니다. 죽기 직전으로 되돌리는 저장 반복을 막습니다.
- **슬롯**: 3개.
- **저장 항목**: 날짜·계절, 자원, 건물(위치·레벨·내구도), 주민 전체 데이터, 관계 행렬, 장비 인스턴스, 진행 플래그, 습격 위협도, 고립 주민과 남은 일수, 유실물 위치, 생존 일지.

## 실패 처리

| 상황 | 결과 |
| --- | --- |
| 필드에서 쓰러짐 | 가방 소실(안전 주머니 2칸 제외). 장착 장비는 쓰러진 자리에 “유실물”로 남아 다음 1회 출격에서 회수 가능. 동행자는 고립. 다음 날 기지에서 깨어남 (의무실이 없으면 하루 동안 최대 체력 −20%) |
| 습격 패배 | 시설 파손, 자원 손실, 주민 부상. 기지가 완전히 무너지지는 않음 (10 습격·방어 탭) |
| 주민이 모두 떠남 | 게임은 계속됨. 방송실 지기(고정 NPC)는 떠나지 않음 |
| 하드코어 옵션 | 플레이어 사망 시 저장 삭제. 기본값은 꺼짐 |

## 데이터 정의

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| day | int | 1부터 시작 |
| season | enum | SPRING, SUMMER, AUTUMN, WINTER |
| phase | enum | MORNING, SORTIE, STAY, EVENING, NIGHT |
| threat | int 0\~100 | 습격 위협도 |
| sortie\_timer | float (초) | 필드 경과 시간 |
| flags | dictionary | 스토리·해금 플래그 |
| stranded | array | 고립 주민 id, 지역, 남은 일수 |
| lost\_gear | array | 유실물 장비 id, 지역, 좌표 |

## 데모 범위

- 하루 흐름 전체, 3\~5일 분량. 계절 없음, 저장 슬롯 1개.
