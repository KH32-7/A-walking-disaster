# 세부 기획

콘텐츠별 세부 기획서입니다. 각 탭은 개발 명세서로 옮길 수 있게 규칙, 수치, 데이터 정의, 데모 범위를 담습니다. **모든 수치는 밸런스 테스트 전 가안**입니다.

개요 탭과 수치가 다르면 이 세부 탭들이 기준입니다. 탭마다 끝에 “데이터 정의”(개발용 필드 목록)와 “데모 범위”(해커톤 시연에 넣을 부분)가 있고, 데모 전체 흐름은 12 진행·밸런스 탭에 있습니다.

1. [01 게임 흐름·시간](01-flow-time.md) — 하루 흐름, 게임 상태, 저장, 실패 처리
2. [02 필드·탐색](02-field.md) — 지역, 소음, 루팅, 구조, 탈출
3. [03 전투·클래스](03-combat-classes.md) — 총·칼·둔기 클래스, 피해 공식, 스킬
4. [04 마물](04-monsters.md) — 마물 계열, 감지 AI, 보스
5. [05 장비·강화](05-gear.md) — 무기·방어구, 등급, 강화, 내구도
6. [06 마법·정수](06-magic-essence.md) — 정수 각인으로 마법 무기 만들기
7. [07 주민](07-residents.md) — 주민 능력치, 직업, 필요, 주민 장비
8. [08 관계·인구](08-relations-population.md) — 연애·결혼·아이 맞이, 편견, 상실
9. [09 기지 건설](09-base-building.md) — 건물, 비용, 개간, 기지 단계
10. [10 습격·방어](10-raids-defense.md) — 습격 발생, 자동 판정, 방어전, 전초기지
11. [11 경제·자원](11-economy.md) — 자원 흐름, 보관, 교역
12. [12 진행·밸런스](12-progression-balance.md) — 성장, 해금 순서, 난이도
13. [13 세계관·내러티브](13-world-narrative.md) — 세계관, 스토리, 퀘스트
14. [14 UI·조작·접근성](14-ui-controls-accessibility.md) — 화면, 조작, 접근성
15. [15 AI 기능](15-ai-features.md) — AI 생성·무전병 명세
16. [16 아트·사운드](16-art-sound.md) — 아트·사운드 방향
