# 아트·사운드

아트는 쿼터뷰 애니풍 스타일라이즈드 3D이고, “쓸쓸하지만 희망적인” 색을 씁니다. 소음이 게임 규칙이므로 **소리 설계가 곧 게임 설계**입니다.

## 아트 방향

- **시점**: 쿼터뷰, 카메라 내려다보는 각 약 55°, 거리 3단계 조절 10 / 13.5 / 18m, 기본은 가운데(2026-11 피드백, 이전 14 / 18 / 24m).
- **렌더링**: Godot 4.7 Forward+, 툰 셰이딩(2\~3단 명암 + 림라이트 + 외곽선). 캐릭터는 MToon(VRoid) 셰이더.
- **팔레트**: 도시는 회백 콘크리트 + 청록 수면 + 초록 덩굴, 하늘은 맑은 파랑(해질녘 주황·분홍). 포인트 색은 네온이는 낮에는 꺼져 있고 네온 계열 마물 주변에서만 켜집니다.
- **기지의 변화**: 학교가 점점 사람 사는 곳으로 바뀝니다. 판자 → 벽돌 → 태양광, 빨랫줄, 화분, 아이들의 그림이 늘어납니다.
- **UI**: 깔끔한 플랫, 무전기 주파수 막대 모티프, 아이콘과 글 함께.
- **레퍼런스**: 명조 호나미 시(분위기만), Pure Nature 2(자연), 애니풍 일본 도시 팩.

## 사운드

- **소음과 소리의 일치**: 플레이어가 듣는 소리의 크기가 실제 소음 반경과 맞아야 합니다. 소음이 생기는 소리에는 모두 화면 링이 따라붙습니다.
- **마물 시그니처**: 수풀은 잎 스치는 소리·꽃망울 터지는 소리, 잔해는 돌 긁힘, 물은 물방울·거품, 네온은 전기 웅웅거림.
- **상태 신호**: 마물이 의심하면 짧은 상승음, 추적하면 경고음. 둘 다 아이콘이 함께 뜹니다.
- **위치 음향**: 3D 위치 음향 + 화면 가장자리 방향 화살표.
- **음악**: 기지는 따뜻한 어쿠스틱(기타·피아노)이고, **인구가 늘면 악기가 하나씩 더해져** 공동체의 성장이 음악으로도 들립니다. 필드는 앰비언트에 추적 시 긴장 레이어, 밤은 낮은 현악, 습격은 타악, 결혼식은 축제 곡.
- **음성**: 방송실 지기는 TTS 또는 성우, 주민은 짧은 감탄사. 모든 대사에 자막.
- **믹싱 우선순위**: 소음 경고 > 무전 > 전투 > 음악.
