# AI 기능

AI는 두 곳에 들어갑니다. 하나는 생존자마다 고유한 사연·대사·개인 요청을 만드는 **생성 파이프라인**, 다른 하나는 상황을 읽고 안내하는 **AI 무전병**(방송실 지기의 목소리)입니다. 두 기능 모두 AI가 실패하거나 인터넷이 없어도 게임이 돌아가게 만듭니다. **수치와 규칙은 게임이 정하고, AI는 문장만 만듭니다.**

## 생존자 생성 파이프라인

1. **템플릿 선택 (규칙)**: 게임이 나이대, 전직, 특성 2개, 참여 조건, 구조 상황, 지역을 고릅니다.
2. **요청**: 위 값과 세계관 요약, 톤 가이드, 금지 목록을 LLM에 보냅니다.
3. **출력**: 아래 JSON 스키마로 받습니다.
4. **검증**: 스키마·길이·금지어·검수 규칙을 검사합니다. 실패하면 1번 다시 생성하고, 그래도 실패하면 미리 쓴 예비 프로필을 씁니다.
5. **저장**: 생성된 텍스트는 세이브에 저장하고 다시 생성하지 않습니다.

| 출력 필드 | 내용 | 제한 |
| --- | --- | --- |
| name | 본래 이름 | 실존 유명인 이름 금지 |
| nickname\_suggestions | 별명 후보 3개 | 각 6자 이내 |
| background | 사연 요약 | 200자 이내 |
| first\_line, rescue\_lines | 첫 대사, 호위 중 대사 3줄 | 줄당 40자 이내 |
| fragments | 신뢰도 20·60에서 공개할 사연 조각 2개 | 각 150자 이내 |
| personal\_requests | 개인 요청 2개 {type, target\_region, target, text} | type은 FIND, ESCORT, CRAFT, PROTECT 중 하나, target\_region은 존재하는 지역 |
| likes, dislikes | 각 2개 | 게임 아이템 목록에 있는 것만 |
| speech\_style, voice\_hint | 말투, TTS 목소리 힌트 | — |

- **사전 생성 vs 실시간**: 해커톤과 오프라인에서는 미리 만들어 사람이 검수한 풀(50명)을 씁니다. 정식 버전은 구조 연출(약 5초) 동안 실시간으로 생성하고, 실패하면 풀에서 꺼냅니다.

## 대화 (선택 기능)

- 하루 대화 1회에 쓰입니다. 입력은 주민 프로필, 최근 사건 5개(생존 일지), 관계 상태, 플레이어가 고른 선택지이고, 출력은 대사 2\~4줄과 감정 태그입니다.
- 플레이어는 자유 입력이 아니라 선택지 3개 중에서 고릅니다.
- 신뢰도 변화는 게임 규칙(07 주민 탭)이 정하고, AI 출력은 수치를 바꾸지 않습니다.
- 꺼져 있거나 실패하면 사연 조각과 템플릿 대사를 씁니다.

## AI 무전병

규칙이 “언제 무엇을 말할지”를 정하고, AI는 그 내용을 방송실 지기의 말투로 만듭니다. 자막은 항상 나오고, 음성은 TTS입니다.

| 상황 (트리거) | 안내 내용 | 제한 |
| --- | --- | --- |
| 같은 지역에서 3번 쓰러짐 | 우회 경로, 추천 장비, 보호 모드 항목 제안 | 출격 전 1회 |
| 3분 동안 목표 진행 없음 | 다음 목표 방향 힌트 | 3분마다 |
| 소음이 계속 큼 | “조용히 움직여” 조언 | 60초 |
| 탄약 20% 미만 / 체력 30% 미만 | 보급·탈출 권유 | 60초 |
| 구조자 체력 낮음 | 숨기 명령 안내 | 60초 |
| 해질녘 | 남은 시간과 가까운 탈출 지점 | 1회 |
| 낮 습격 | 예상 결과 구간(자동 판정 공식으로 계산) + 귀환 권유 여부 | 1회 |
| 아침 방송 | 소문, 날씨, 습격 징후, 말벌리는 한마디 | 매일 |

- **빈도 설정**: 끔 / 필요할 때(기본) / 자주. 같은 유형은 60초 안에 다시 나오지 않고, 전투 중에는 한 줄만 말합니다.
- **오프라인**: 유형마다 템플릿 문장 5개를 돌려 씁니다.

## 생존 일지와 에필로그

- 하루 사건 로그(구조, 결혼, 사망, 편견 해소, 개인 요청 완료)를 한 줄 기록으로 바꿔 일지에 남깁니다. 예: “12일차. 지은이 처음으로 웃었다.”
- 엔딩 에필로그는 주민별 일지를 요약해 만듭니다.
- 실패하면 사건 종류별 템플릿 문장을 씁니다.

## 검수 규칙

| 구분 | 규칙 |
| --- | --- |
| 금지 | 장애·나이·출신·성별 비하, 동정 위주 묘사(“불쌓한”), 영웅화(“장애를 극복한”), 특정 국가·민족 고정관념, 실존 인물, 잔혹한 묘사 |
| 필수 | 사연마다 전문성이나 일상의 디테일 1개 이상, 필요와 기여가 함께 드러남 |
| 이주민 대사 | 서툰 한국어를 희화화하지 않음. 짧은 문장 + 모국어 단어 한두 개 정도 |
| 마물 흔적 | 흔적이 있는 사람이 실제로 위험하다는 암시 금지 |
| 자동 검사 | 금지어 사전 + 두 번째 LLM 호출로 위 규칙 체크리스트 판정 |
| 사람 검수 | 사전 생성 풀은 팀이 전부 읽음. 가능하면 당사자나 관련 단체의 의견을 받음 |

## 기술 구성 (가안)

- **경로**: Godot HTTPRequest → 백엔드 프록시(API 키 보관) → LLM API. 게임 클라이언트에는 API 키를 넣지 않습니다.
- **모델 예시**: 생존자 생성·검수는 Claude Sonnet 5.5, 실시간 대사·무전은 응답이 빠른 Claude Haiku 5.5.
- **타임아웃**: 5초. 넘기면 대체 텍스트.
- **비용 관리**: 생성은 사전 생성과 캐시 위주, 실시간 대화는 설정에서 켜는 선택 기능.
- **개인정보**: 플레이어가 지은 이름·별명과 게임 상태만 보내고, 그 외 개인정보는 보내지 않습니다. 설정의 “AI 끄기”로 완전히 오프라인으로 할 수 있습니다.

## 데모 범위

- 사전 생성·검수한 주민 3명, 무전병 트리거 5종(템플릿 + TTS), 생존 일지 템플릿. 실시간 대화는 네트워크가 있을 때 보여주는 선택 시연.
