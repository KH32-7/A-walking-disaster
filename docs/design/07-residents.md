# 주민

주민은 이름·사연·능력치·특성을 가진 한 사람 한 사람입니다. 작업장에 배정하면 일하고, 장비를 입히면 경비·동행·방어를 맡습니다. 장애·나이·출신은 “특성”이 아니라 **참여 조건과 사연**으로 표현합니다.

## 주민 데이터

| 항목 | 내용 |
| --- | --- |
| 이름·별명 | 본래 이름 (별명은 지금 짓지 않음) |
| 나이대 | 아이 / 청소년 / 성인 / 노인 |
| 성별·외형 | 표시용. 능력치와 역할에는 영향 없음 |
| 전직 | 목수, 간호사, 의사, 정비공, 전기기사, 요리사, 농부, 교사, 통역사, 라디오 PD, 경찰, 운동선수, 화가, 학생 등. 초기 능력치와 시설 해금에 연결 |
| 특성 | 2개 (아래 표) |
| 좋아하는 것 / 싫어하는 것 | 각 2개 (음식, 물건, 작업) |
| 참여 조건 | 0\~2개. 채워주는 포용 시설이 있음 (아래 표) |
| 능력치 | 힘, 손재주, 감각, 마음 (1\~10) |
| 작업 숙련 | 직업별 0\~5 |
| 클래스 적성 | 총·칼·둔기 각각 상/중/하 |
| 상태 | 배고픔, 피로, 건강, 사기 |
| 신뢰도 | 플레이어와의 관계 0\~100 |
| 관계 | 다른 주민과의 관계 −100\~100 (08 관계·인구 탭) |
| 사연·개인 요청 | AI로 생성 (15 AI 기능 탭) |

## 능력치

| 능력치 | 쓰이는 작업 | 전투 영향 |
| --- | --- | --- |
| 힘 | 벌목, 채석, 해체, 건설, 개간 | 둔기 피해 +3%/점, 체력 |
| 손재주 | 정비, 재봉, 목공, 정수 공방 | 칼 피해 +3%/점 |
| 감각 | 경비, 정찰 | 총 확산 −3%/점 |
| 마음 | 농사, 요리, 의료, 돌봄, 교육, 무전·외교 | 같은 작업장 동료 사기 +1/일 (7 이상) |

- **초기값**: 전직의 주 능력치 5\~7, 나머지 2\~5 사이에서 무작위.
- **성장**: 그 능력치를 쓰는 작업을 10일 하면 +1(최대 10). 교실에서 배우면 2배 빠름.
- **나이대**: 아이는 작업 대신 놀이·배움(돌봄방·교실). 청소년은 가벼운 작업(텍밭, 부엌, 정찰 보조)만 하고 효율 0.7, 전투 배정 불가. 성인 1.0. 노인은 교육·의료·요리 효율 1.2.

## 참여 조건

참여 조건은 “그 사람이 할 수 없는 것”이 아니라 **기지가 아직 갖추지 못한 것**입니다. 시설을 지으면 불이익이 사라집니다.

| 조건 | 예 | 채우는 시설 | 시설이 없을 때 |
| --- | --- | --- | --- |
| 이동 | 휠체어 사용자, 거동이 불편한 노인 | 경사로·승강기 (구역별) | 그 구역 작업장에 배정 불가 |
| 언어 | 한국어가 서툰 이주민 | 그림 표지판(효율 회복), 통역 무전기(무전·외교 가능) | 효율 −30% |
| 청각 | 청각장애가 있는 주민 | 경광등(시각 경보), 그림 표지판 | 습격 경보를 늦게 알아 대피 10초 지연 |
| 돌봄 | 어린 아이를 둔 보호자 | 돌봄방 | 하루 작업 효율 0.5 |

경험이 다르면 보이는 것도 다릅니다. 예를 들어 수어를 쓰는 주민과 동행하면 동행 명령에 소리가 나지 않습니다(02 필드·탐색 탭의 “경험이 여는 길”).

## 특성

| 특성 | 효과 |
| --- | --- |
| 부지런함 | 작업 효율 +10% |
| 느긋함 | 작업 효율 −10%, 피로 증가 −20% |
| 용감함 | 전투 중 도주하지 않음, 경비 전투력 +10% |
| 겁이 많음 | 체력 30% 이하에서 도주, 대신 습격 때 대피가 가장 빠름 |
| 대식가 / 소식가 | 식량 소모 +1 / −1 |
| 예민한 귀 | 경비 배정 시 습격 예고 +6시간 |
| 조용한 발걸음 | 동행 시 이동 소음 −2m |
| 손이 빠름 | 제작 작업 +15% |
| 수다쟁이 | 모닥불 관계 증가 ×2 |
| 혼자가 편함 | 관계 증가 ×0.5, 혼자 일하는 작업장 효율 +15% |
| 낙천적 / 비관적 | 사기 하한 30 / 사기 상승 ×0.7 |
| 연애에 관심 없음 | 연애 이벤트 대상이 아님, 우정 관계 증가 +30% |
| 편견 | 특정 주민에게 관계 증가 ×0.3. 해소 이벤트로 사라짐 (08 탭) |
| 마물 흔적 | 정수 공방 효율 +50% (06 탭), 편견 이벤트의 대상 |

## 상태와 필요

| 상태 | 범위 | 변화 | 영향 |
| --- | --- | --- | --- |
| 배고픔 | 0\~100 | 하루 −40, 식사 +50(요리 +70) | 20 미만: 효율 −30%, 사기 −10/일. 0: 체력 감소 |
| 피로 | 0\~100 | 작업일 +30, 휴식일 −60, 잠자리(침상 −40, 숙소 −50) | 80 초과: 효율 −30% |
| 건강 | 정상/부상/질병 | 부상: 전투·습격. 질병: 겨울·배고픔 낮을 때 확률 | 부상은 작업 불가 3일(의무실 1일). 질병은 하루 10% 확률로 전염, 의약품으로 치료 |
| 사기 | 0\~100 | 아래 표 | 0\~19 떠날 위기 / 20\~39 효율 0.8 / 40\~69 1.0 / 70\~100 1.2 + 특별 대화 |

| 사기 요인 | 변화 |
| --- | --- |
| 좋아하는 일 배정 / 싫어하는 일 | +3 / −3 (매일) |
| 요리 식사, 모닥불·식당 | +2\~3 (매일) |
| 친구와 같은 작업장 | +2 (매일) |
| 침상 없음(임시 거처) | −10 (매일) |
| 결혼식 / 아이 맞이 | +15 / +10 (전원, 1회) |
| 동료 사망 | −10\~−30 (관계에 따라) |
| 동료 고립 중 | −5 (전원, 매일) |
| 습격 패배 | −10 (전원) |

사기가 20 미만으로 3일 이어지면 “떠나려 한다” 이벤트가 뜹니다. 플레이어가 대화로 붙잡거나(신뢰도 40 이상이면 성공) 원하는 것을 들어주면 남습니다.

## 직업

| 직업 | 작업장 | 주 능력치 | 하루 기본 효과 |
| --- | --- | --- | --- |
| 벌목 | 벌목장 | 힘 | 나무 8 |
| 채석 | 채석장 | 힘 | 돌 6 |
| 해체 | 고철 해체장 | 힘 | 고철 4 (잔해 필요) |
| 농사 | 텍밭 | 마음 | 식량 6 (한 칸당) |
| 요리 | 부엌 | 마음 | 식량 효율 ×1.5, 사기 보너스 |
| 목공 | 목공소 | 손재주 | 나무 8 → 목재판 4 |
| 정비 | 정비소 | 손재주 | 탄약·소모품 제작, 자동 수리 |
| 재봉 | 재봉실 | 손재주 | 방어구 수리, 천 가공 |
| 정수 연구 | 정수 공방 | 손재주 | 정제, 정수 전지 |
| 의료 | 의무실 | 마음 | 하루 2명 치료, 구급상자 제작 |
| 교육 | 교실 | 마음 | 학생 능력치 성장 ×2 |
| 돌봄 | 돌봄방 | 마음 | 아이 4명 돌봄 → 보호자가 일에 나섬 |
| 경비 | 경비 초소·성벽 | 감각 | 기지 방어력 (10 습격·방어 탭) |
| 정찰 | 전초기지 | 감각 | 위협도 감소, 소문 수집 |
| 방송 | 방송실 | 마음 | 아침 방송, 구조 대상 소문, 교역 연결 |
| 건설·개간 | 건설 현장·개간 구역 | 힘 | 진행도 10/일 |
| 휴식 | — | — | 피로 −60 |

```latex
O = B \times (1 + 0.1S) \times (1 + 0.15K) \times F_{morale} \times F_{tool} \times F_{access}
```

O = 하루 생산량, B = 기본 효과(표), S = 주 능력치, K = 작업 숙련(같은 작업 7일마다 +1, 최대 5), F\_morale = 사기 배율, F\_tool = 도구 배율(기본 1.0, 좋은 도구 1.3), F\_access = 참여 조건 배율(충족 1.0).

## 클래스 적성과 주민 장비

- **적성**: 계열마다 상(피해 +15%, 스킬 사용 가능) / 중(보정 없음) / 하(피해 −30%).
- **전투 역할**: 경비(기지), 동행(필드), 파견(전초기지). 아이·청소년은 배정 불가.
- **전투 수치**: 체력 80 + 힘 × 5 + 방어구, 명중은 감각, 피해는 무기 × 적성 × 능력치 보정.
- **장착**: 주민 상세 화면에서 무기고의 장비를 입힙니다(주무기, 보조무기, 방어구 4칸). 무기 없는 경비는 방어력 기여가 1/3입니다.
- **유실**: 고립된 주민의 장비는 구출하면 돌아오고, 실종되면 함께 사라집니다.

| 단계 | 수치 | 해금 |

| 낯섬 | 0 | — |
| 경계 풀림 | 20 | 사연 1 |
| 믿음 | 40 | 개인 요청 1, 떠날 위기 때 붙잡기 가능 |
| 가까움 | 60 | 사연 2, 고유 특기 |

**오르는 법**: 하루 대화 1회 +3, 선물(좋아하는 것 +8, 보통 +3, 싫어하는 것 −5), 개인 요청 완료 +20, 함께 출격해 살아 돌아옴 +5, 고립에서 구출 +15.

## 새 식구 인사 (2026-11-06, 이전 "입주 의식" 5단계를 대신함)

구한 사람이 기지에 오면 대화 한 번으로 맞이합니다. 고르거나 채울 것은 없습니다.

1. 기지 도착 연출 (주민들이 마중)
2. 한 줄 인사: "고마워요, 덕분에 살았어요. 저는 ○○이에요." 아래에 사연의 첫 조각, 좋아하는 것 하나, 잠자리를 작은 메모로 보여 줍니다.
3. "반가워요"를 누르면 입주가 끝나고 좋아하는 것 하나를 알게 됩니다. 여러 명이면 다음 사람이 이어서 인사합니다.

- **침상**: 들어올 때 빈 침상에 자동으로 배정됩니다. 없으면 임시 거처(사기 −10/일)이고, 침상이 생기면 옮길 수 있습니다.
- **별명, 외형**: 고르지 않습니다. 외형은 나이, 성별, 전직, 이동 방식으로 정해진 캐릭터 모델을 씁니다.
