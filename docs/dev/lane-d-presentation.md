# 레인 D — 표현·콘텐츠

모든 UI 화면과 HUD, 아트 에셋 임포트·셰이더·머티리얼, 맵 꾸미기(dressing), VFX, 사운드·음악,
`assets/` 서브모듈 관리를 맡는다. 게임 규칙은 계산하지 않고, A·B·C의 신호와 getter만 화면에 그린다.

- 주로 다룬 폴더(기록, M2 이후 소유권 없음): `ui/`, `art/`, `audio/`, `vfx/`, `levels/**/dressing.tscn`, `data/ui/`, `tests/ui/`, `assets/` 포인터(M2까지는 D만 올렸다)
- 이미 있는 뼈대: `UI`, `Audio`, `Fx` 오토로드
- 개발 장소: `ui/_preview/`(가짜 데이터로 화면 미리보기), 각 레벨의 `dressing.tscn`

### D-01 UI 테마 + 화면 스택 · M0 (모두가 기다림)
- 만들 것: `ui/theme/` Godot Theme(글꼴 크기 3단계, 색 토큰, 대비 높음 변형), 등급·속성 **색 + 모양** 아이콘 세트(원·사각·삼각·마름모·별 / 꽃잎·사각·물방울·번개), `UI.open/close` 화면 스택, HUD 레이어, 자막 컴포넌트(2줄, 화자 이름).
- 참고: `docs/design/14-ui-controls-accessibility.md` "UI 규칙", `05-gear.md` "등급"

### D-02 에셋 파이프라인 · M0
- 만들 것: `assets/` 폴더 규칙(`assets/characters`, `assets/environment`, `assets/monsters`, `assets/audio` ...), `assets/LICENSES.md`(에셋마다 출처·라이선스·다른 엔진 허용 여부), Unity 패키지에서 FBX·텍스처만 꺼내는 절차, 임포트 프리셋.
- 완료 조건: 라이선스 확인 항목(다른 엔진·상업 이용·재배포 금지·AI 제한)이 채워진 에셋만 들어간다. 유료 파일은 메인 저장소에 하나도 없다.
- 참고: `docs/design/16-art-sound.md` "에셋 조달", 루트 `CLAUDE.md` 에셋 규칙

### D-03 툰 셰이더 · M0
- `art/shaders/` 2~3단 명암 + 림라이트 + 외곽선, 속성 4색 발광 머티리얼, 투명화(실내 지붕) 셰이더. 참고: `16-art-sound.md` "아트 방향"

- `noise_emitted` → (월드 링은 2026-11-06 사용자 요청으로 뺌) 마물 "?"·"!", 화면 밖 방향 화살표. Settings `sound_arrows`를 따른다.

### D-06 기지 HUD + 건설·주민 UI · M1
- 상단 막대(날짜·계절·자원·인구/침상·전력·위협도), 하단 메뉴, 알림, 건설 패널(분류·비용·조건, 미리보기는 C), 주민 목록·상세(능력치·특성·참여 조건·장비 칸·신뢰도·사연).

### D-07 출격 준비·결과·정산 · M1
- 지역 지도(위험도·소문·유실물), 장비·가방, 동행자 선택 → `SceneRouter.go_to_field(loadout)`. 결과 화면(가져온 것·구한 사람·잃은 것), 저녁 정산 표(`evening_settled` 리포트).

### D-08 가방·무기고 · M1
- A-08 API 위의 격자 UI(드래그·회전·버리기·안전 주머니), 무기고·창고 목록, 장비 비교 툴팁(등급 색 + 모양).

### D-09 캐릭터 파이프라인 · M1
- VRoid Studio → VRM → Godot. `addons/vrm`(godot-vrm) 도입과 플러그인 활성화는 **A에게 요청**(project.godot). 플레이어·주민 외형 프리셋 5종 이상(머리·색·옷 조합), 공용 휴머노이드 애니메이션 리타깃. B·C는 결과 씬을 인스턴스만 한다.

### D-10 dressing (침수 상가·기지) · M1
