# 레인 C — 기지

건설, 주민 시뮬레이션, 관계·인구, 습격·방어, 기지 맵 레이아웃을 맡는다.
UI는 D, 자원 저장은 A(`Economy`), 장비는 A(`Armory`), 전투 동작은 B의 컴포넌트를 쓴다.

- 소유: `base/`, `data/{buildings,traits,jobs,events,raids}/`, `levels/base/**`(`dressing.tscn` 제외), `tests/base/`
- 이미 있는 뼈대: `Colony` 오토로드
- 개발 장소: `base/_sandbox/`

### C-01 기지 샌드박스 + 마커 · M0
- 만들 것: `base/_sandbox/base_sandbox.tscn`, `base/markers/` — `BuildArea`, `ZoneMarker`, `ResourceNode`(나무·잔해), `RaidSpawnPoint`, `WorkSpot`, `OutpostNode`. 에디터 전용 표시.
- 완료 조건: D가 기지 dressing에서 마커를 볼 수 있다.

### C-02 주민 데이터 모델 · M1
- 만들 것: `base/defs/` 의 주민 관련 스키마(07 탭 데이터 정의), `data/traits/`(07 탭 특성 표), `data/jobs/`. `rescue_completed` → 주민 생성(`data/resident_pool/`의 검수된 프로필 사용, A-16 전에는 손으로 쓴 3명), `resident_joined` 발신, 침상 배정.
- 완료 조건: `Colony` 저장·불러오기 왕복 테스트.
- 참고: `docs/design/07-residents.md`

### C-03 격자 건설 · M1
- 만들 것: 1칸 = 2m, 배치·회전·겹침 금지·개간된 칸만·통로 연결 검사, 건설 현장 → 진행도(작은 10·중간 30·큰 60, 주민 1명 하루 10 + 힘 보정, 기지에 머무르면 +20), 이동 무료, 철거 50% 반환. 건설 모드 입력·미리보기 메시는 C, 건물 목록 패널은 D-06.
- 참고: `docs/design/09-base-building.md` "건설 규칙"

### C-04 건물 데이터 + 효과 · M1
- 만들 것: `base/defs/building_def.gd`, `data/buildings/`(09 탭 목록 전부, 데모 8종 먼저), 효과: 인구 상한, 창고 한도(`Economy.set_cap_bonus(창고 보너스 합)`로 반영), 전력 수급·우선순위, 소음도.
- 참고: `docs/design/09-base-building.md` "건물 목록", "전력", "기지 소음도"

### C-05 작업 배정 + 하루 정산 · M1 (A-05가 기다림)
- 만들 것: 작업장 정원, 배정 API, 생산 공식 O = B × (1+0.1S) × (1+0.15K) × 사기 × 도구 × 참여, 식량 소비, 숙련 증가, `Colony.settle_day() -> Dictionary`(A-05가 호출). 탄약 같은 제작 작업은 A-09 함수를 호출.
- 완료 조건: 11 탭 "기지 생산 기준"(주민 4명: 나무 +25/일 등)이 재현된다.
- 참고: `docs/design/07-residents.md` "직업", `11-economy.md`

### C-06 필요·사기 · M1
- 배고픔·피로·건강·사기 구간, 사기 요인 표, 떠날 위기 이벤트(신뢰 40 이상이면 붙잡기 성공). 참고: `07-residents.md` "상태와 필요"

### C-07 주민 행동 · M1
- 기지 맵 내비게이션, 작업장으로 출근·퇴근, 모닥불·식당, 침대, 머리 위 필요 상태 신호(아이콘 표시는 D). 캐릭터 모델은 D-09 결과를 인스턴스.

### C-08 습격 판정 · M1 (A-05가 기다림)
- 만들 것: 위협도 공식(T + 3 + 소음 + 계절 − 2P − G), 발생 표, 5일차 유예, 하루 1회, `Colony.roll_raid(time) -> Dictionary`, 자동 판정 R = 방어력 / 강도 → 결과 4단계와 피해 적용, `raid_warning/started/resolved`. 예상 결과 구간 함수(A-14 무전이 씀).
- 참고: `docs/design/10-raids-defense.md` "위협도", "발생 규칙", "자동 판정"

### C-09 기지 숲 공터 레이아웃 · M1
- `levels/base/base_school/`(경로 이름은 그대로 둠) 의 `base_school.tscn`(조립), `layout.tscn`(공터·방송실 야영지·개간 숲 3곳, 숲 가장자리 벽, 호수·연못 충돌, 내비, 마커). 꾸미기는 `dressing.tscn`(`art/dressing/forest_dressing.gd`), 건물 모델 조합표는 `base/building/building_models.gd`, 미리보기 `base/_sandbox/forest_clearing/`.

### C-10 개간 + 기지 단계 · M2
- 구역 7곳, 개간 진행도·획득 자원·묻힌 상자 이벤트, 기지 단계 조건, 시설 레벨(Lv2 ×2 + 부품 5, Lv3 ×3 + 희귀 부품 3)과 단계별 상한(A-09가 읽음).
- 참고: `09-base-building.md` "구역과 개간", "기지 단계"

### C-11 참여 조건 + 포용 시설 · M2
- 조건 4종(이동·언어·청각·돌봄), 구역별 충족 판정(경사로·승강기·표지판·경광등·돌봄방·교실), 효율 배율, 접근성 보기용 데이터(`Colony.access_map()`, 화면은 D).
- 참고: `07-residents.md` "참여 조건", `09-base-building.md`

### C-12 신뢰도·대화·선물 · M2
- 하루 1회 대화(+3), 선물(+8/+3/−5), 단계 해금. 대사 문장은 A(`Radio`/AI 대화), 화면은 D-13.

### C-13 입주 의식 · M2
- 흐름 데이터: 이름·별명·외형 프리셋 선택 결과 저장, 침상 선택, 첫 대화. 화면은 D-13.

### C-14 관계 + 밤 이벤트 · M2
- 관계 수치·단계, 요인 표, 감소, 밤 이벤트 풀(모닥불·다툼·고백·데이트·청혼·결혼식·이별), 결혼식 날 축제, `relationship_changed`, `night_event_started`.
- 참고: `docs/design/08-relations-population.md`

### C-15 아이 맞이 + 성장 · M2
- 조건, 매일 5% 대화, 출산(10일)·입양(가족 구성과 무관), 아이 데이터(외형 혼합·특성 유전), 성장 단계(아기 0~9일 ~ 성인 50일), 교실 20일 → 숙련 1단계 전수.

### C-16 편견 이벤트 체인 · M2
- 소문 → 선택 3가지 → 사건 → 해소, "마물 흔적" 특성, 정수 공방 보너스(A-10과 맞춤). 이야기 안에서 흔적이 있는 사람은 마물이 되지 않는다.

### C-17 직접 방어전 · M2
- 기지 맵 3파, 파 사이 20초 준비(함정 재설치, 경비 배치), 승패 조건, 자동 판정으로 넘기기(+20%). 전투는 B-23 컴포넌트, HUD는 D-14.
- 의존: B-23

### C-18 방어 시설 · M2
- 10 탭 표 전부(벽 3종·문·초소·함정·소음 미끼·정수 등불·조명탑·경보·대피소), 내구도·수리, 방어 기여값.

### C-19 전초기지 · M2
- 월드맵 노드, 주둔 2명, 유지비, 방향별 강도 −25%, 하루 전 예고, 전초기지 습격 20%.

### C-20 고립·실종·사망·추모 · M2
- `companion_stranded` → 5일 타이머(Settings `strand_days`), 실종, 사망·장례·슬픔·추모비, 보호자 승계.

### C-21 낮 습격 · M2
- 출격 중 판정, `raid_warning`(60초 전, 초소 없으면 즉시), B-22 긴급 귀환 연결, 계속 탐색 시 자동 판정.

### C-22 이주 · M3 / C-23 계절 효과 · M3
- 방송실 Lv2 이주 무리, 계절별 생산·연료·사기 보정.
