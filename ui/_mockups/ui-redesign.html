해솔시 UI 재설계 시안

전투 HUD를 뺀 모든 화면을 다시 그렸습니다. 덕코프 1.0 플레이 영상의 화면을 우리 화면과 하나씩 짝지어 보고, 기지와 건설은 컬트 오브 더 램의 흐름을 더했습니다. 아래 그림은 모두 HTML로 그린 시안이고 게임 파일은 건드리지 않았습니다.

지금 화면이 왜 안 읽히나

코드로 직접 확인한 것은 건설 화면(ui/screens/build_screen.gd)과 기지 HUD(ui/hud/base_hud.gd) 두 곳입니다. 나머지는 영상 비교에서 나온 차이입니다.

건설 화면

  • 건물 43종이 글자 줄로만 나온다. 한 줄에 이름, "생산 · 2×2칸", 비용 글, "지을 수 있음"뿐이라 생김새도 하는 일도 알 수 없다.
  • 설명이 없다. 오른쪽 카드에 비용·전력·소음·일손 숫자만 있고 "이 건물이 무엇을 하는지" 한 줄이 없다.
  • 놓은 다음이 안 보인다. "배치하기"를 누르면 창이 닫히고 끝. 건설 현장 → 주민 보내기 → 진행이라는 순서를 화면이 알려 주지 않는다.
  • 분류 탭 11개(주거·생산·가공·생활·제작·포용·저장·군사·특수·설비·방어)가 같은 크기 글자 버튼으로 늘어선다.

기지 HUD

  • 위 막대 한 줄에 열 가지(날짜·단계·자원 6종·창고·인구·침상·전력·위협도)가 같은 굵기로 붙어 있어 먼저 볼 것이 없다.
  • 아래 메뉴가 글자 버튼 7개. 기지는 걸어 다니는 곳인데 시설 앞에 가도 할 수 있는 일이 월드에 뜨지 않는다.
  • 무엇을 지어야 하는지 모른다. 기지 단계(캐프 → 정착지 → 요새) 조건이 어디에도 안 보인다.

고치는 원칙 네 가지

  1. 그림 먼저, 글은 다음. 건물·아이템·주민은 미니 모형과 아이콘으로 먼저 알아보게 한다.
  2. 순서가 있는 일은 순서를 보여 준다. 건설은 ①고르기 ②놓기 ③짓기를 화면 위에 늘 띄운다.
  3. 기지는 걸어서 쓴다. 시설 앞에서 [F] 목록(덕코프), 메뉴 버튼은 지름길로만.
  4. 노랑은 지금 누를 버튼 하나. 판은 슬레이트 목록판, 크림 읽을거리, 월드 표지 세 가지만.

03 · 건설 모드

건설: 고르기 → 놓기 → 짓기

"좌라락 뜨는 목록"을 그림 카드 격자로 바꾸고, 건설이 세 단계라는 걸 화면 위 띠로 늘 보여 줍니다. 컬트 오브 더 램처럼 메뉴 뒤 월드는 흑백으로 가라앉고, 놓을 때는 월드 색을 바꿔 칸을 또렷하게 합니다.

  • 상세 카드에 "하는 일" 한 줄과 "지어지는 과정"(놓기 → 일손 보내기 → 진행)을 쓴다.
  • 잠긴 건물도 자리를 차지한다(컬오램). 자물쇠 + 무엇이 필요한지.
