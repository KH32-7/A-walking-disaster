# 해솔시 UI 규칙

레인 D의 모든 화면·HUD는 이 문서를 따른다. 레퍼런스는 아크 레이더스 플레이 영상(1:12:18 전체를 12초 간격으로,
앞 10분은 3초·0.1초 간격으로 분석)이다. **느낌과 구조만 가져오고** 로고·무지개 띠·고유 아이콘·문구는 베끼지 않는다.
수치는 1920×1080 기준 px이다. 다른 해상도는 `UI`가 화면 크기에 맞춰 배율을 곱한다.

---

## 1. 원칙

1. **세상이 주인공이다.** 필드 HUD에는 판(panel)을 깔지 않는다. 얇은 흰 선, 숫자, 글자 한 줄과 그림자만 쓴다.
   HUD는 화면 가장자리 40px 안쪽 네 구역에만 놓는다.
2. **메뉴는 두 겹이다.** 반투명 슬레이트 판에 목록을 담고, 읽어야 하는 것(툴팁, 확인창, 설명, 보상)은
   크림색 카드에 담는다. 어두운 판은 "목록", 크림 카드는 "읽을거리"다.
3. **기본 규칙은 아크 레이더스다.** 이 문서의 모든 규칙은 아크 레이더스 방식이 기준이고, 덕코프는 아래 "메뉴 스킨" 표에
   적힌 항목에만 덧붙인다. 표에 없는 것은 아크 방식을 따른다. 두 방식이 부딪히면 아크를 따른다.
   필드 HUD는 선과 숫자만 쓰는 아크 레이더스 방식 그대로 둔다.
   Tab으로 여는 메뉴와 기지 화면은 아크의 정리된 열 구성·크림 카드·노랑 강조·키 안내 줄을 유지하면서, 덕코프의
   예쁨을 더한다. 둥근 판, 아이콘 원 탭, 등급색이 아래에서 번지는 칸, 칸 아래 이름, 판 안 머리띠, 뒤 장면이
   보이는 옅은 흐림이 그 예쁨이다(§4 "메뉴 스킨").
4. **노랑은 할 일에만 쓴다.** 노랑은 지금 누를 버튼(수락, 출격, 확인), 고른 항목, 보상 수치, 안내 카드 머리띠에만
   쓴다. 장식에는 쓰지 않는다.
5. **모든 조작에 키를 붙인다.** 화면 아래 줄에 지금 쓸 수 있는 키를 `[Esc] 뒤로 [Tab] 가방 …`처럼 늘 보여 준다.
   월드 상호작용도 `[F] 뒤지기` 한 줄이다. 게임패드면 같은 자리에 버튼 글리프를 보여 준다.
6. **색만으로 구분하지 않는다.** 등급·속성·관계·위협도는 색에 모양이나 글을 함께 붙인다(기획 14 "UI 규칙").
7. **움직임은 짧게 한다.** 메뉴는 바로 열리고 툴팁은 바로 뜬다. 애니메이션은 보상, 진행, 확인, 수색처럼
   의미가 있을 때만 쓴다(§6).

영웅 `#B072E8` 마름모 · 전설 `#F29A3A` 별.
칸에서는 왼쪽 아래 모서리 삼각형(18px)과 왼쪽 위 모양 배지(14px)로 표시한다. 툴팁에서는 태그 칩에 모양과
글자를 함께 쓴다.

**속성**(색 + 모양, 기획 06): 초록 `#7BD86A` 꽃잎 · 돌 `#B9A27A` 사각 · 물 `#5FC2FF` 물방울 · 빛 `#FFD84A` 번개.

**고대비**(`Settings.high_contrast`): `SLATE` 불투명도를 0.96으로, `LINE`을 0.6으로 올리고 `TEXT_DIM`을 `TEXT`로,
HUD 그림자를 외곽선 2px로 바꾼다. 크림 카드는 그대로 둔다.

## 3. 글자

| 역할 | 글꼴 | 크기 (보통) | 비고 |
|---|---|---|---|
| 화면 제목 | Pretendard Bold | 30 | "출격 결과", "정비소" |
| 섹션 머리 | Pretendard Bold | 20 | "가방 18/30"처럼 개수를 옆에 붙임 |
| 본문 | Pretendard Medium | 16 | 줄 간격 1.45 |
| 보조 | Pretendard Medium | 13 | 단위, 출처, 각주 |
| 숫자·키 | Barlow SemiBold | HUD 22 / 큰 탄약 44 | 고정폭 숫자(`010`), 영문 키 이름 |
| 탭 | Pretendard SemiBold | 20 | |

- 한글은 Pretendard, 숫자와 영문 키 이름은 Barlow를 쓴다(둘 다 OFL, `ui/theme/fonts/`).
- 영문 대문자는 자간 +3%를 준다. 한글에는 자간을 주지 않는다.
- 글자 크기는 `Settings.text_size`에 따라 3단계다: 0 작게 ×0.875, 1 보통 ×1.0, 2 크게 ×1.25.
  자막 크기는 `subtitle_size`를 따로 따른다.
- 탄약은 3자리로 채운다(`018`). 시간은 `MM:SS`로 쓴다.

## 4. 배치

### 필드 HUD (가장자리 여백 40px)

나침반은 두지 않는다. 쿼터뷰와 미니맵으로 방향이 보이고, 기획 14에도 없다(아크 레이더스와 다른 점).

| 구역 | 요소 |
|---|---|
| 왼쪽 위 | 미니맵(기획 14): 판 없이 원 테두리만. 플레이어 화살표, 탈출 마름모(`GOOD`), 목표 사각(`ACCENT`), 동행 원(`INFO`), 들린 마물 삼각(`DANGER`). 밖에 있는 표시는 테두리에 붙임 |
| 오른쪽 위 | 출격 타이머(`해질녘까지 MM:SS`, 3분 미만이면 `WARN` 색 + ▲ 아이콘) → 목표 목록(오른쪽 정렬, 주 목표는 `ACCENT` 세로 띠와 진행 글) |
| 왼쪽 아래 | 동행 한 줄(이름 · 명령 · 얇은 막대) → 내 이름(왼쪽에 `INFO` 세로 띠) → 방어 막대(4칸) → 체력 막대(흰색) |
| 오른쪽 아래 | 보조 행동 목록(`정수 해방 │ [X]`) → 소모품 칸(번호 머리 + 아이콘) + 무기 스택(번호·이름 줄, 고른 무기는 흰 바탕에 검은 글, 그 아래 탄약 44px과 `≡ 예비`) |
| 왼쪽 가운데 | 보상 알림: 노란 XP 칩과 글 한 줄. 최대 4줄, 2.6초 뒤 흐려짐 |
| 오른쪽 가운데 | 안내 카드: 노란 머리띠 + 크림 본문 + 키 칩. 한 번에 하나 |
| 왼쪽 위 1/3 | 지역 진입 카드: 핀 원 + 두 줄(작은 글 "해솔시 · 3일차 · 맑음", 큰 글 "침수 상가 광장") |
| 아래 가운데 | 위에서부터 자막(최대 2줄, 화자 이름은 `ACCENT`) → `[키] 행동` 안내 → 길게 누르기 막대(괄호 모양) → 스태미나 괄호 막대(가득 차면 숨김) |
| 월드 위 | `[키] 행동` 한 줄, 소음 링, 마물 `?`·`!`, 화면 밖 방향 표시, 거리 표시 `◆ 탈출 42m` |

### 메뉴 (가방·지도·기록·시스템, 기지 화면들)

- **위 줄**: 가운데에 탭(고른 탭은 둥근 외곽선)을 두고, 오른쪽에 재화·자원 요약(아이콘 + 숫자)을 둔다.
  기지 화면이면 왼쪽에 `<` 뒤로 원 버튼과 `장소 — 부제`(예: `정비소 — Lv 2`)를 둔다.
- **본문 판**: 좌우 52px, 위 110px, 아래 100px 여백을 두고 `SLATE` 판을 깐다.
  세로 열로 나누고 각 열 위에 섹션 머리를 둔다.
- **아래 줄**: 왼쪽에 키 안내(테두리 알약 키 + 글), 오른쪽에 보조 정보(동행 얼굴, 대화 키).
### 메뉴 스킨: 아크 + 덕코프

| 항목 | 아크에서 유지 | 덕코프에서 더함 |
|---|---|---|
| 뒤 장면 | 메뉴 뒤를 흐린다 | 흐림 8px, 어둡게 35%만. 장면 색이 비쳐 보이게 한다 |
| 판 | `SLATE` 열 구성, 섹션 머리 + 개수 | 모서리 14px, 불투명도 0.78, 판 맨 위에 `SLATE_2` 머리띠(모서리 10px)를 두고 제목·개수·버튼을 그 안에 넣음 |
| 탭 | 위 가운데, 지금 탭 강조 | 글자 대신 아이콘 원(지름 60). 고른 탭은 `INFO` 빛 원 + 아래 작은 글(`13/30칸`). 나머지는 아이콘만, 마우스를 올리면 이름 |
| 칸 | 1.5px 테두리, 개수 `×N`, 내구도 | 모서리 10px. 등급색이 칸 아래에서 위로 번짐(일반 없음, 고급 이상 30~45%). 칸 아래쪽에 이름 11px(1×1은 줄임표). 등급 모양 배지는 왼쪽 위 |
| 장비 칸 | 무기는 넓은 카드(이름·탄약·내구도) | 장비 칸 아래에 부위 이름(`주무기`, `머리`) |
| 소모품 칸 | 퀵슬롯 열 | 가방을 열면 화면 아래 가운데에 소모품 줄이 떠오르고 "끌어다 놓아 소모품 칸 정하기" 안내와 번호 키 칩을 보여 줌 |
| 버튼 | 노랑 기본·회색 취소 | 판 머리띠 안의 작은 버튼은 연하늘 알약(`#E6F4FF`, 글 `#1D3D55`) |
| 툴팁·우클릭·확인창 | 크림 카드 그대로 | 바꾸지 않는다 |
| 아래 키 안내 줄 | 그대로 | 그대로 |
| 열고 닫기 | 바로 바꾼다 | 0.12초 페이드만 넣는다. 칸이 새로 들어오면 0.2초 동안 0.6→1.08→1 크기로 튀어나옴 |

토큰 추가: `PANEL_RADIUS 14`, `SLOT_RADIUS 10`, `PILL_SOFT #E6F4FF`, `PILL_SOFT_TEXT #1D3D55`, `TAB_GLOW #6CC8FF`.

- **장면형 화면**(주민 상세, 시설, 상인·퀘스트): 왼쪽 55%는 3D 장면을 그대로 두고, 오른쪽에 흐린 판 +
  크림 카드를 둔다. 아래쪽에 큰 알약 버튼 1~2개를 놓는다(위: 크림 "받기", 아래: 어두운 "훈련").
- **지점 표지**(기지 전경에서 시설·주민 고르기): 어두운 칩 두 줄(작은 이름 / 큰 역할) + 가는 지시선 + 흰 점.
  고르면 오른쪽에 이미지 + 크림 설명 카드가 뜬다.

## 7. 해솔시만의 규칙 (레퍼런스에 없는 것)

- 쿼터뷰라 월드 표시는 화면 좌표로 그린다. 표시가 화면 가장자리 60px 밖으로 나가면 가장자리에 화살표로 남긴다.
- **소음 링**: 크기에 따라 흰색(6m 미만) → 주황(15m 미만) → 빨강, 두께는 2/4/6px. 0.7초 동안 퍼지며 흐려진다.
- **마물 표시**: `?`는 노랑 원(의심), `!`는 빨강 삼각(추적). 둘 다 검은 외곽선을 둘러 어떤 배경에서도 보이게 한다.
- **주민 머리 위**: 필요(배고픔·피로·아픔·슬픔)는 어두운 알약 안에 아이콘과 글로 표시한다.
  급하면 `WARN` 글자. 대화할 수 있으면 말풍선 아이콘.
- **위협도**: 막대를 안전·주의·위험 3구간으로 나눈다. 위험 구간에는 빗금을 넣고 눈금과 글(`주의 46`)을 함께 쓴다.
- **포함 시설**(경사로 등)은 `INFO` 아이콘 + 글로 표시한다. 장애를 색으로만 표시하지 않는다.

## 8. Godot 구현 지침

- 테마는 `UiThemeBuilder.build(text_size, high_contrast)`가 `UiTokens`로 코드에서 만든다.
  `ui/theme/haesol_theme.tres`는 에디터 미리보기용 기본값(보통, 고대비 끔)이다.
- 타입 변형(theme type variation) 이름: `PanelSlate`, `PanelSlateInner`, `CardCream`, `CardCreamFoot`,
  `ButtonPrimary`, `ButtonSecondary`, `ButtonCancel`, `ButtonSpecial`, `TabText`, `LabelTitle`, `LabelSection`,
  `LabelDim`, `LabelOnCream`, `LabelOnCreamDim`, `LabelNumber`, `LabelHud`. 씬에서는 이 이름만 쓴다.
- 화면은 `UI.open(&"bag")`로 연다. 화면 스택은 `UI`가 관리하고, Esc는 맨 위 화면을 닫는다.
  HUD는 `UI.hud`, 알림·자막은 `UI.overlay` 레이어에 둔다.
- 게임 규칙은 계산하지 않는다. 값은 `EventBus` 신호와 `contracts.md`의 getter로만 받는다.
  데이터가 없으면 `ui/_preview/`의 가짜 데이터로 그린다.
- 새 컴포넌트를 만들면 §5 표에 한 줄 추가한다. 이 문서를 바꾸면 PR에 "UI 규칙 변경"이라고 적는다.
